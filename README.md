**GasOptimizer** — это специализированное десктопное приложение для автоматизированного расчета и оптимизации распределения инжектируемого топлива (природного газа) между параллельно работающими доменными печами металлургического цеха.

Проект разработан в рамках исследования систем оптимального управления технологическими процессами в металлургии (УрФУ).

## 🎯 Описание решаемой задачи

В современных условиях работы доменных цехов технологические показатели отдельных агрегатов существенно различаются. Программа решает задачу линейного математического программирования, находя глобальный оптимум распределения лимитированного объема природного газа по группе печей. 

**Целевая функция:** Максимизация общей экономической эффективности цеха (снижение затрат на кокс и газ) при выполнении заданного плана по выплавке чугуна.

**Учитываемые технологические ограничения:**
* Допустимые диапазоны расхода природного газа ($V_{min}$, $V_{max}$) для каждой печи.
* Цеховые лимиты на общий расход газа и запасы кокса.
* Выполнение планового задания по суммарному производству чугуна.
* Сохранение качества чугуна (ограничения по содержанию серы $[S]$).
* Сохранение теплового баланса (контроль изменения теоретической температуры горения на фурмах).

## ✨ Ключевые особенности

* **Математическое ядро:** Интеграция высокопроизводительного решателя `Google.OrTools (GLOP)` для мгновенного симплекс-анализа.
* **Чистая архитектура:** Приложение построено на строгом паттерне **MVVM (Model-View-ViewModel)**. Визуальная разметка (XAML) полностью изолирована от бизнес-логики и математических алгоритмов.
* **Динамичность:** Возможность добавления, удаления и редактирования параметров любого количества доменных печей «на лету».
* **Надежность (UX):** Защита от ошибок пользовательского ввода (универсальный парсинг разделителей дробей — точек и запятых).
* **Отчетность:** Встроенный сервис генерации и экспорта детализированных результатов оптимизации в формат `.csv` для последующего анализа.

## 🚀 Как запустить программу

Вам не нужно устанавливать среду разработки или .NET, чтобы воспользоваться программой. Она собрана в единый автономный исполняемый файл со всеми встроенными C++ библиотеками решателя.

📥 **[Скачать актуальную версию (.exe)](https://github.com/ruzzel666/GasOptimizer/releases/latest)**

*Просто скачайте файл и запустите его на любом ПК под управлением Windows (x64).*
